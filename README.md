
# QuickNotes 📝

QuickNotes is a simple, responsive note-taking web application built with HTML, CSS, and JavaScript. It helps users create, organise, search, and manage notes by category.

## Features

- Add notes with Personal, Work, or Study categories.
- Validate note input and enforce a 200-character limit.
- Display the date and time each note was created.
- Delete individual notes.
- Search notes using case-insensitive text matching.
- Display the total number of notes.
- Save notes in browser localStorage so they survive page refreshes.
- Responsive layout for desktop and mobile devices.

## Technologies Used

- HTML5
- CSS3 (Flexbox and media queries)
- JavaScript (DOM manipulation and event handling)
- Browser localStorage
- Git and GitHub

## Getting Started

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser, or use the Live Server extension.
4. Start adding and managing your notes.

No additional dependencies or installations are required.

## How to Use

1. Enter a note in the text field.
2. Select Personal, Work, or Study.
3. Click **Add Note**.
4. Search for notes using the search field.
5. Click **Delete** to remove an individual note.

Notes are stored in the current browser's localStorage.
